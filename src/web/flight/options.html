Studio's stick shaper Gimbalyn, in place of Joystick Gremlin

Studio can shape your stick itself, in place of Joystick Gremlin: it reads your real stick, applies the curves you set on Stick setup and feeds vJoy, which Elite reads. With "Switch the curves when Flight Assist changes in the game" ticked below, it follows Flight Assist by itself, so there is no Gremlin profile to set up. It is off until you turn it on, and Studio never takes vJoy before that.

    Both Studio and Joystick Gremlin write to vJoy, and only one can. Turn Gremlin's profile off while Studio shapes the stick. In Elite, set the dead zone of pitch, roll and yaw to 0: your curves already have one.

    Flight inputs overlay

    The throttle hand and the stick hand drawn over the game, as "Your hands, live" on Stick setup draws them. It never takes the mouse, so you fly with it up. Elite must be in Borderless (Options › Graphics › Display).

    On: it comes up by itself when Flight Assist goes off, and goes when Flight Assist comes back on. Off: it never comes on screen, not even with its key.
